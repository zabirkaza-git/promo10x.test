# Promo 10x – Irfan Khairi

Landing page pemasaran untuk perkhidmatan **Promo 10x** oleh Irfan Khairi.

---

## 🚀 Cara Menjalankan Projek

### Menggunakan XAMPP (Disyorkan)

1. Pastikan XAMPP telah dipasang dan modul **Apache** sedang berjalan.
2. Projek ini berada di dalam direktori:
   ```
   c:\xampp\htdocs\iksb\promo10x\
   ```
3. Buka pelayar web dan layari:
   ```
   http://localhost/iksb/promo10x/
   ```
